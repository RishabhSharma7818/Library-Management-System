# Library Management System (Java)

This is a simple Library Management System built using Java and OOP concepts.  
It includes classes for Books, Users, and Library operations such as issuing and returning books.

## Features
- View all books
- Issue a book
- Return a book
- View users (dummy data)

## Technologies Used
- Java
- VS Code

## How to Run

### Clone the Repository

```bash
git clone https://github.com/RishabhSharma7818/Library-Management-System.git
```

### Run the Program
1. Open the project in VS Code
2. Navigate to the `LibraryManagementSystem` folder
3. Run the `LibraryManagementSystem.java` file
